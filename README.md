# Orca Products

A consolidated suite of professional-grade trading tools for NinjaTrader 8.

## Included Products

### Indicators
- **Orca Anchored VWAPs**: Dynamic anchored VWAP with customizable standard deviation bands.
- **Orca Rolling Profiles**: Real-time rolling volume profiles.
- **Orca Time VWAPs**: Session-based VWAPs with high-visibility metrics.
- **Orca Absorption Candles**: Identifies market absorption levels within candles.
- **Orca Candle Volume Profile**: Detailed volume profile per candle.
- **Orca Cumulative Delta**: Precision tracking of cumulative delta.
- **Orca Execution Lines**: Links execution markers on the chart for better trade visualization.
- **Orca Leg-to-Leg Profile**: Custom range volume profiles between any two points.
- **Orca Step Profile**: Incremental volume profile tracking.
- **Orca Tick Direction Index**: Analyzes tick-level order flow.
- **Orca Time Statistics**: Statistical analysis of time-based trading data.
- **Orca Visual Orders**: Enhanced visual management for orders.

### Add-Ons
- **Orca Risk Manager**: Comprehensive risk management and position sizing tool.
